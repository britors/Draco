Features

Everything you need to work with PostgreSQL

From the first SELECT to server maintenance, in a single window.

Full SQL editor

Tabs, highlighting, schema-aware autocomplete, query or script execution, EXPLAIN and cancellation aimed at the operation's own backend.

Explorer and ERD

Lazy browsing of schemas, tables, views, functions, procedures, sequences and triggers, global search and a navigable ER diagram.

Result grid

Virtualized results, row detail, TSV copy, CSV/JSON export and paginated editing by primary key.

Administration

Dashboard, activity and locks, roles, extensions, pg_cron, pg_stat_statements and maintenance with VACUUM/ANALYZE.

Programming + GitHub

A dedicated editor for views, functions, procedures and triggers, with branches, diffs against the deployed database, commits and pull requests.

AI assistant

Anthropic, OpenAI or Gemini per connection, with read-only tools and SQL review for security, performance and readability.

Backup and restore

Cancellable operations with pg_dump, pg_restore and psql, with paths redacted from logs.

Native SSH tunnel

SSH and jump hosts handled in process with russh, without calling the ssh executable. TLS via rustls.

Secure by default

Your credentials are never stored in plain text

Draco Postgres is designed to work with real production databases without leaking secrets.

  • System keyring. Passwords, passphrases and API keys live in GNOME Keyring, KWallet or Credential Manager — never in configuration files.
  • Clean logs. SQL, results and credentials never appear in logs or error messages.
  • Explicit confirmation. Destructive changes require confirmation, including typing the name when it applies.
  • Read-only AI. The assistant inspects the database but never runs DDL or DML; suggestions are text for you to review.
  • No network in the interface. A fully local interface, with no CDN, a strict CSP and minimal IPC.

Install Draco Postgres

Native packages for version 2.1.4, built from an immutable tag.

openSUSE via OBS

The official RPM is on the Open Build Service, in the home:rodrigosbrito:lyra project. Once the repository is added, Zypper delivers updates automatically.

sudo zypper addrepo https://download.opensuse.org/repositories/home:/rodrigosbrito:/lyra/openSUSE_Leap_16.1/home:rodrigosbrito:lyra.repo
sudo zypper refresh
sudo zypper install postgres-draco

The package is called postgres-draco because draco is already taken in openSUSE; the installed application is still Draco. Package page on OBS →

Frequently asked questions

Questions about Draco Postgres

Is Draco Postgres free?

Yes. Draco Postgres is free software, licensed under GPL-3.0-or-later, and can be used at no cost, including in commercial environments.

Which operating systems does Draco Postgres run on?

There are native packages for Ubuntu (.deb), Fedora and openSUSE (.rpm) and an installer for Windows. You can also build it from source on any modern Linux distribution.

Do I need psql to use Draco Postgres?

No. Queries use a native PostgreSQL driver. Only backup and restore use the official pg_dump, pg_restore and psql tools.

Where are my passwords stored?

In the operating system's credential store, such as GNOME Keyring, KWallet or Windows Credential Manager. Draco Postgres never writes passwords to configuration files.

Can the AI assistant change my database?

No. The assistant only inspects the database with read-only tools. Any SQL it suggests is shown as text for you to review and run yourself.
